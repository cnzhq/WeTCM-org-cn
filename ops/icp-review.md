# ICP 备案内容核查

核查日期：2026-10-13（Asia/Hong_Kong）。对象：本地 Docusaurus 主站源码、配置、构建产物、部署流程；外部依据为现行政府公开文本与阿里云接入指南。没有访问备案账户、执照、域名实名资料、服务器或 GitHub Discussions 后台。通过浏览工具访问主站、百科和日历均未取得可读内容，因此不声称线上已核验。

## 结论与适用边界

本次已处理用户指出的标题、编号、截图首页区块及指定介绍，并同步页脚版权主体。剩余较明确的核查重点是：中医/保健内容分类及准确性、教材转载授权、评论治理，以及真实主体与域名/申报材料的一致性。

“可能导致复核/驳回”是基于源码和指南的风险判断，不是管局已认定违法或一定拒绝的结论。页面变简洁、加免责声明、隐藏首页入口，都不能替代真实申报和内容授权。

法规版本必须区分：2024 年版《非经营性互联网信息服务备案管理办法》第十一条仍列有医疗保健等行业[1]；2024 年 12 月修订后的《互联网信息服务管理办法》第五条已不再逐项列出医疗保健、药品和医疗器械[2]。2025 年相关药品/医疗器械信息服务由审批改为备案管理[3]，江苏已提供相应办理事项[4]。因此不能套用旧网页，断言“只要有中医文字就必须办旧资格证”。是否属于专业医疗保健、药品信息或其他专项服务，应按真实服务向接入商及江苏相关主管部门核实。
